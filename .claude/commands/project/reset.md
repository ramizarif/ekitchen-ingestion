# Project Reset

Reset the multi-agent coordination system to a clean state.

## Reset Operations

### 1. Clear Active Agents
- Remove all entries from coordination files
- Archive completed agent records
- Clear pending approval requests

### 2. Clean Implementation Plans
- Archive current implementation plans
- Clear pending plans directory
- Reset plan numbering/tracking

### 3. Reset System State
- Clear conflict tracking
- Reset performance metrics
- Clean temporary coordination files

### 4. Preserve History
- Backup current state before reset
- Archive completed work records
- Maintain audit trail

## Safety Measures

1. **Backup current state** before any reset operations
2. **Confirm reset scope** with user
3. **Preserve completed work** records
4. **Maintain system integrity** throughout reset

## Instructions

1. **Ask for confirmation** before performing any destructive operations
2. **Show what will be reset** and what will be preserved
3. **Perform backup** of current coordination state
4. **Execute reset** operations safely
5. **Verify system health** after reset
6. **Report final state** and readiness for new work

Use this command only when the coordination system needs to be completely reset due to corruption or major changes.
